command_id: launch:user-directory
---

A macOS application bundle defaults to `~/Library/Application Support/OpenTS/` when the option is absent. In a bundle, the debug log, [out-of-sync reports](/using/out-of-sync-reports/) and [crash reports](/using/crash-reports/) stay in that default directory whatever the option names. On Windows, and for a plain macOS executable, those three go into folders beside the executable. [Game data](/using/game-data/) lists the files the directory receives.
